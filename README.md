# MA BILLIARD — содержимое приложения

Приложение MA BILLIARD скачивает файл `content.json` из этого репозитория.
Чтобы добавить тренера, клуб, рекламу или статью, отредактируйте `content.json`
на сайте GitHub (значок карандаша → **Commit changes**). Обновлять приложение не нужно:
изменения видны после обновления списка (потянуть вниз) или при следующем открытии.

Картинки кладите в папку `img/` и указывайте путь вида `img/club-1.jpg`.

## Тренер (`coaches`)

```json
{
  "id": "ivanov",
  "name": "Иван Иванов",
  "city": "Москва",
  "photo": "img/ivanov.jpg",
  "offline": true,
  "online": false,
  "levels": ["новички", "юниоры"],
  "disciplines": ["свободная пирамида"],
  "rank": "МС",
  "experience": "10 лет",
  "price": "от 2500 ₽ / час",
  "club": "БК «Пример»",
  "about": "Пара строк о себе.",
  "phone": "+7 900 000-00-00",
  "telegram": "@username",
  "promo": { "advertiser": "ИП Иванов И. И.", "erid": "2Vtzq...", "from": "2026-12-01", "until": "2026-12-31" }
}
```

## Клуб (`clubs`)

```json
{
  "id": "club-1",
  "name": "БК «Пример»",
  "city": "Москва",
  "address": "ул. Примерная, 1",
  "hours": "ежедневно 12:00–02:00",
  "tables": "10 столов 12 футов",
  "tablePrice": "от 600 ₽ / час",
  "photo": "img/club-1.jpg",
  "phone": "+7 900 000-00-00",
  "telegram": "@club",
  "site": "https://example.ru",
  "about": "Описание.",
  "promo": { "advertiser": "ООО «Пример»", "erid": "...", "from": "2026-12-01", "until": "2026-12-31" }
}
```

## Реклама (`ads`)

```json
{
  "id": "ad-1",
  "title": "Турнир выходного дня в БК «Пример»",
  "text": "Суббота, 12:00. Взнос 1000 ₽.",
  "image": "img/ad-1.jpg",
  "link": "https://example.ru",
  "category": "club",
  "placements": ["home", "news"],
  "cities": ["Москва"],
  "promo": { "advertiser": "ООО «Пример»", "erid": "...", "from": "2026-12-01", "until": "2026-12-31" }
}
```

- `placements`: `home` — главная, `news` — лента новостей, `blog` — блог.
- `cities`: показывать только в этих городах (пусто — везде).
- Без `promo.advertiser` блок не показывается.
- Категории `alcohol`, `betting`, `tobacco`, `gambling`, `casino`, `vape`, `adult` и тексты
  со словами про ставки, алкоголь и табак приложение **не показывает никогда**: им пользуются дети.

## Платное размещение и закон

Каждый платный блок приложение помечает: «Реклама · рекламодатель · erid».
По закону «О рекламе» (ст. 18.1) интернет-рекламу нужно зарегистрировать через оператора
рекламных данных (ОРД) и получить токен `erid`. Его вписывают в `promo.erid`.
`promo.from` / `promo.until` — даты оплаченного показа; после `until` блок исчезает сам,
а тренер или клуб остаётся в каталоге без значка «Партнёр».

## Статья (`posts`)

```json
{
  "id": "slug",
  "title": "Заголовок",
  "date": "2026-11-12",
  "rubric": "Техника",
  "author": "Автор",
  "cover": "img/post.jpg",
  "summary": "Одна строка для списка.",
  "body": "Текст в формате Markdown: ## подзаголовки, **жирный**, списки 1. и -",
  "promo": { "advertiser": "…", "erid": "…" }
}
```

`promo` у статьи — только для платных публикаций.

## Примеры

Записи с `"example": true` показываются с пометкой «пример». Удалите их, когда появятся настоящие.
